テトリスの基礎。

以下のように、1 列空けて平たく積む形を平積みという。

```
_______
xx_xxxx
xx_xxxx
```

組みやすいのは一番端に穴を空ける方法。

T-Spin も狙いたいなら3列目を空けて、2-7積みにするといい。ただ、積むのは難しくなる。
2積み側はJ/L/I/Oで積むか、S/Z/Tで積むかになるが、Tスピンの際に切り替わるのが基本。Z,Jで凹みを作ったり、L,SやJ,I,Sで凹みを作ったり。O,ZやZ,LでTSTを作る場合もある。

テトリスの棒を刺す列を端以外にすると途中でTスピンも狙えるのが利点。

平積みは端に向かって3-4段の階段を作っておくとS/Zミノ縦置きで折り返してから屋根を作ればTSDを狙える。
あと端から2列目は使わないので、階段でなく端にOミノが置ける状態でも同じことができる。
J/Lミノで折り返すこともでき、TSSを狙える。
最悪OミノやTミノで穴を埋めずに凌ぐこともできるので、穴に向かって階段を作るのが平積みの基本。まずは端をいきなり埋めずに1列1段空けて階段にするのを意識するといい。
穴の横の列が1段下がっているだけで、S/Z/J/Lミノも穴を埋めずに凌げる。

基本的に、ミノ、特に S/Z ミノを縦に積んでしまうと山になる。

どうしても縦に積まないといけない場合、壁際に積むと影響が少ない。
ただ、これも邪魔ブロックが端に来ると崩すのに時間がかかるのでできるだけ避ける。

ミノを一つずつ捉えているとどうしても縦に積むことになる。
基本的に、O ミノ以外のミノは尖っている。
重要なのは、ネクストを見て、相性のいい組み合わせで大きな四角として積むこと。

- S + L (赤青)
- Z + J (緑橙)
- S/Z + L + J (赤青橙/緑青橙)
- T + L/J (紫青/紫橙)
- T + T + L/J (紫紫青/紫紫橙)
- O + L/J (黄青/黄橙)
- O + L + J (黄青橙)
