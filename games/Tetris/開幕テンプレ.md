## 開幕TSDテンプレの基本形

```
___JJJXXXX
L__ZZJSXXX
L___ZZSSOO
LL_IIIISOO
```

一巡目でTSDを狙える。
2手目以内にIミノが来るか、S, Z, JミノよりもIミノが早く来ないと使えない。

## TDテンプレ

https://note.com/blueceru55/n/naf29b8cc1ebd

山岳積み２号と呼ばれるテンプレが主流。97%で全消しも狙える。ただし、組むのに時間がかかるので、途中で攻撃されると全消しにはならない。

以下の二つが一巡目の形。
Lが早い場合はLを下にして、Jをホールドする。
Jが早い場合はJを下にして、Lをホールドする。

```
___J______
___J______
__JJ____ZI
__T____ZZI
OOTTSS_ZLI
OOTSS_LLLI
```

あるいは左右反転して、

```
______L___
______L___
IS____LL__
ISS____T__
IJS_ZZTTOO
IJJJ_ZZTOO
```

あとはS, Zミノをもう一つ上に重ねて、他のミノで適当に隙間を埋めるだけ。

以下の形になると97%でパーフェクトを狙える。
一番上のXXXXの部分にIミノを寝かせて、他のミノで残りを埋める。8段目までの80マスでパーフェクトになる。
パーフェクトまでにTSDを経由せずに、他のミノで埋めるパターンが3割ある。

```

XXXX__X__X
XXX___XXXX
XXX_XXXXXX
```
