# Resource

エネルギーを取り出せるもの。
何かに活用できるもの。

動力や能力を持つもの。

- 土地
- 燃料
- 人間や動物
- 資本
- など

資源は集中するのが基本。

何をどれくらい持っていて、
何が使われてて、
何が使われてないか、
何が壊れているか、

管理している資源が多いほど、手がかかる。AIなどで管理しやすくするメリットも大きくなる。逆に、管理している資源が少ないと自分でなんとかなる。

時間は資源じゃないけど、資源を使うための枠みたいな感覚。
時間がないとそもそも資源を使えないし、資源によっても枠を占有する数が違って一つの枠でどの資源をどのくらい使えるか決まっている。
